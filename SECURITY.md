# Security policy

To report a vulnerability in any repository in the `sensive-ai`
organization, or in the Sensive service its SDKs talk to, email
security@dynax.co. Please don't open a public issue or pull request.

Each SDK's repository says which of its versions are supported, and a fix
goes into every supported version. Once a fix is released, we publish a
security advisory in the affected repository, crediting you if you would
like.
